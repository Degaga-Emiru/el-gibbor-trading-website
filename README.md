# EL GIBBOR Import & Export PLC - Company Management System

A modern company website and internal staff management system developed for **EL GIBBOR Import & Export PLC** using React, TypeScript, Tailwind CSS, Vite, and Supabase.

The platform provides a public website for showcasing the company's products and services, together with a secure staff portal for employee management, tasks, reports, and product management.

---

## Features

### 🌐 Public Website
- Home, About Us, Services, Products, Gallery, Careers, and Contact pages.
- Dynamic products, new arrivals, and company content.
- Public customer contact form.

### 🔐 Staff Management
- Secure Supabase authentication with email verification and OTP.
- Role-based access for **Managers** and **Employees**.
- Employee management, task assignment, and work reports.
- Product management and media uploads.
- Manager dashboard for monitoring company activities.

---

## 🛠️ Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Supabase
- **Database:** PostgreSQL
- **Authentication:** Supabase Auth
- **Storage:** Supabase Storage
- **Security:** Row-Level Security (RLS) & RBAC
